# Workspace (/workspace)

Mode: Operate. Audience: the same researchers and students who came from the front page. Job: add files, search passages, ask questions with citations, read sources, compare, extract, export. Constraints from the user (structured question, 2026-11-23): restyle in place, keeping every layout, feature and behaviour; the interface in Martian Mono with a proportional face for long reading (documents, answers, excerpts); dark mode kept as the same system inverted.

## Direction contract

THESIS: The workspace joins the front page's instrument sheet so the product reads as one thing, while staying a quiet tool: familiar layouts, the red only where something is primary, selected or live.

OWN-WORLD: Light grey ground #f1f1ef with white panels and #0b0b0b ink (dark: #0b0b0b ground, #161616 panels, #f1f1ef ink); 1px frames and hairline rules, square corners, no block shadows; signal red #d3110f for focus, selection marks, progress and the live states; former pastel state fills become neutral greys and a pale red tint; Martian Mono for the interface, Anton only for the page title, Source Serif 4 for reading text.

STORY: The visitor arrives from the front page and recognises the same sheet: the page title in Anton, mono controls with black primary buttons, then reads documents and answers in a calm serif.

FIRST VIEWPORT: The existing workspace layout unchanged: the sidebar rail with the active item as a black bar, the Anton page title, the upload area framed by a 1px dashed red line, the document library in hairline rows.

FORM: Extension of the established front-page world onto an existing surface. No structure roll ran, because the user chose to restyle in place and keep every layout (structured question, 2026-11-23); there is no seed for this surface.
